# 存款续航计算器

纯静态网页，可在浏览器中直接打开，也可以通过 Vercel 部署。

## 功能

- 自定义存款本金、年度支出、年利率
- 可增删、修改存款和支出档位的对照表
- 根据剩余本金按月计息，估算资金耗尽时间
- 导出 CSV；浏览器本地保存设置

## 使用与修改

网页源码位于 [index.html](./index.html)，不需要构建工具。

本仓库默认分支为 `master`，该分支连接 Vercel 自动部署：提交至 `master` 后，Vercel 应自动构建并更新站点。

## 计算说明

模型采用固定名义年利率、每月均匀支出，未考虑通货膨胀、所得税、利率变动和提前支取损失；仅供情景测算，不构成理财建议。
